# Blockchain Forensics

Public portfolio focused on blockchain forensics, crypto AML, on-chain investigations and reproducible financial crime analysis.

## Repository structure

- `cases/`: public investigation case studies using public or synthetic data;
- `tools/`: reviewed Python, SQL and automation tools;
- `docs/`: publishable technical notes and methodology;
- `portfolio/`: index of professional artifacts.

This repository contains selected public work. Internal rules, learning plans and unfinished investigations are kept private.

## Method

Investigations distinguish facts, inferences and hypotheses, document sources and limitations, and prioritize reproducibility.

## Status

The portfolio is being developed progressively. New material will be published only after review for accuracy, privacy and reproducibility.
