# Blockchain Forensics

Case studies and notes on crypto AML and on-chain financial crime investigation.

## Cases

- [The Crypto Fraud Cycle Doesn't Start at KYC](cases/crypto-fraud-cycle-doesnt-start-at-kyc.md). Why crypto fraud keeps working after onboarding is done. It covers the stages a fraudulent account moves through from a clean sign-up to cash-out, the main types of money mule, and the problem of proving who controls a wallet that no institution holds. Checked against FATF, Elliptic, and Chainalysis.
- [New Account, Escalating Deposits: Tracing a Multi-Bridge Consolidation Pattern](cases/new-account-escalating-deposits-multi-bridge-tracing.md). A synthetic AML case taken from alert to decision, following the FinCEN SAR narrative structure and a Tier 1 / Tier 2 escalation flow. All figures are fictional.

## How the cases are written

Each one keeps observed facts separate from inferences and hypotheses. Sources are cited. What could not be verified is stated rather than skipped. Cases built on real public reporting say so; cases invented as exercises are labeled synthetic.

## Folders

- `cases/`: The case studies above.
- `tools/`: Python and SQL tooling, once there is any worth publishing.
- `docs/`: Technical notes meant to be read on their own.
- `portfolio/`: CV and portfolio index.

Learning plans, internal notes, and unfinished work stay out of this repo.
